# PM APEX

Pokémon Masters Audio Player EX is an audio player for Pokémon Masters audio tracks

It is a small hobby project aiming to create an audio player dedicated to Pokémon Masters EX soundtracks

## Download and Installation

So let's get to the point, how to install and run this

1. Download pm-apex.rar from [here](https://github.com/V-Play-Games/pm-apex/raw/release/pm-apex.rar)
2. Extract the zip to an empty folder.
3. Run pm-apex.bat file.

## Note

1. The Audio Player can play tracks online only.
2. Download functionality has been removed in this feature. It'll be introduced again soon.
